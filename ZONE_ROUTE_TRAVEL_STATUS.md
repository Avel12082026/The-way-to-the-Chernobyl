# Переходы между локациями — 29.09.2026

Новая механика заменяет мгновенный переход полноценным маршрутом.

- Для завершения любого перехода нужны 10 побед в боях.
- Тир врагов равен тиру локации назначения.
- Побег из боя не засчитывается как победа.
- Аномалии, дружественные NPC-торговцы и случайный хабар встречаются между боями, но не увеличивают счётчик.
- Прогресс 0/10 хранится на сервере и переживает перезапуск Telegram/WebView.
- Смерть удаляет активный маршрут и возвращает игрока на базу по штатной механике смерти.
- После 10-й победы локация назначения сохраняется в worldPosition и открывается штатный экран загрузки.

Текущие маршруты: Кордон ↔ Свалка, Свалка ↔ НИИ Агропром, Свалка ↔ Росток, Росток ↔ Темная долина, Темная долина ↔ Янтарь.

Тир определяется направлением: например Кордон → Свалка = 2, Свалка → Агропром = 3, Агропром → Свалка = 2, Свалка → Росток = 4.

Серверный патч: `server_patches/zone_route_travel_20260929.patch`.
Установщик: `tools/install_zone_route_travel.sh`.
Клиент: `ui/bunker-menu.js`, ZoneMap API 0.9.0 / BunkerMenu 1.23.0.

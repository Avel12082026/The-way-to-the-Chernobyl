# Текущее решение — цельные бойцы, 23 сентября 2026

Последнее указание пользователя отменяет старую сборку частей тела: не использовать отдельные кисти, плечи, предплечья и модульные руки. Под неподходящее оружие рисовать цельного персонажа с новой позой.

Игрок всегда слева, смотрит вправо. Враг справа, смотрит влево. Весь спрайт врага отражается целиком: броня, оружие и хват сохраняют взаимное положение.

## Реализовано локально
- images/combat/fighters.js: точный выбор цельного спрайта по armorId:weaponId, общая высота, линия земли и отражение врага.
- images/combat/scene.js: цельные персонажи, без загрузки и отрисовки отдельных рук. Неизвестная пара отображается сообщением о неготовом облике, не подменяется другим снаряжением.
- index.html передаёт снаряжение игрока и доступные поля экипировки противника.
- Два новых цельных PNG: 1:12 и 40:12 (Юность / Титан-Про с АК-74). Созданы built-in imagegen из референсов костюма и АК-74. Запрос: цельный персонаж, хват рукояти и цевья, приклад у плеча, прозрачный фон, направление вправо.
- Проверка направления: images/combat/fighters-preview.html; тест tests/combat_fighters.test.cjs.

## Ограничения и продолжение
Только две пары имеют новые цельные рисунки. Остальные автоматы и снайперские винтовки, все костюмы, попиксельная проверка всей коллекции ещё не завершены. На действующем сервере нужно проверить, какие поля экипировки возвращает встреча с NPC; отсутствие этих данных не следует компенсировать угадыванием по тиру. - weapon-fit/fitting/weapons: 116 отдельных моделей (26 пистолетов/револьверов, 90 тяжёлых); административное оружие 85 исключено.

## Правила
Персонаж и ствол направлены вправо. Для пистолетов вытянутые руки; для тяжёлого оружия хват двумя руками. Сохранять броню, маски, капюшоны, противогазы и перчатки из инвентаря. Шевроны пустые. Без вспышек выстрела. Прозрачный только фон; персонаж и оружие непрозрачны.
Цевьё лежит в опорной ладони; рукоять внутри кулака, виден лишь маленький соединённый с ней край снизу. Пальцы целые, указательный достигает спуска. Последнее указание по прикладу: длинный приклад допускается поверх плеча, у АКС-74У оставить прежний длинный видимый приклад. Укороченная версия отвергнута.

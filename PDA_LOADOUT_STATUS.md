# КПК: предметы в профиле

Готовы клиент и серверная правка по актуальному server-current.js, полученному от владельца проекта.

Персонаж поднят; под ним шесть слотов артефактов 3×2, одного размера с оружием и детектором. Нажатие на каждый предмет открывает описание с кнопкой «Выход». Текстовый список и подписи снаряжения убраны.

Публичный профиль получает artifactSlots, equippedArtifactDetails и armorUpgradeData только для надетой брони. Именные и гибридные артефакты отображаются с характеристиками просматриваемого экземпляра. Порядок пустых слотов сохраняется. Инвентарь, склад и улучшения другой брони не раскрываются.

Серверная правка: server_patches/pda_loadout.json; установщик: tools/install_pda_server_patch.py. Установщик проверяет SHA-256 исходной версии, синтаксис Node.js и создаёт резервную копию. База данных не меняется. Полный серверный файл не публикуется в GitHub.

Проверены публичная проекция, разделение данных игроков, 288 вариантов брони, 756 вариантов оружия/детекторов, восстановление портрета. Chromium 320/390/768: размеры слотов, сетка 3×2, пустые позиции, 27 открытий/закрытий описаний без ошибок JS.

Сервер установлен владельцем 2026-09-11 через pocketzone.service (systemd). Публичный API проверен после перезапуска: шесть слотов, шесть надетых артефактов и шесть соответствующих определений; поле улучшений надетой брони присутствует, инвентарь и склад отсутствуют. Резервная копия: /var/www/pocketzone/server.js.before-pda-20260911_021430.

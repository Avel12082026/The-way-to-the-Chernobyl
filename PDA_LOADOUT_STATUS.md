# КПК: предметы в профиле

Клиент подготовлен: персонаж поднят и уменьшен по высоте; под ним шесть слотов артефактов, два ряда по три. Размер слота совпадает с оружием и детектором за счёт общей сетки из пяти колонок. По нажатию на оружие, детектор, броню или артефакт открывается описание с кнопкой «Выход». Подписи и нижний текстовый список снаряжения удалены.

## Блокер публикации

Проверка рабочего GET /api/player/:id 2026-09-11: armor, weapon и detector присутствуют, artifactSlots и armorUpgradeData отсутствуют. Клиент не может восстановить чужие надетые артефакты. Отсутствующие данные показаны как «Нет данных», настоящие пустые позиции — пустыми рамками.

Нужен актуальный серверный исходник. Найденный server_balance_v41.js от 2026-09-06 имеет старую реализацию публичного маршрута и не соответствует работающему серверу. Его нельзя устанавливать вместо текущего сервера.

В существующую безопасную проекцию публичного профиля добавить:

- artifactSlots: ровно шесть позиций в исходном порядке, строка с точным именем надетого артефакта или null. Сохранять невидимый суффикс экземпляра для поиска определения; не уплотнять массив через filter(Boolean).
- armorUpgradeData: только запись для надетой брони, по существующему стабильному ключу. Не раскрывать улучшения предметов в инвентаре.
- Для именных и гибридных артефактов подтвердить, что их определения и характеристики доступны через уже существующие каталоги клиента. При необходимости передавать публичные определения только шести надетых экземпляров.

Не возвращать весь объект игрока, инвентарь, склад, служебные поля или приватные данные. Не менять авторизацию и сохранение состояния.

После серверной правки проверить публичный профиль игрока с частично заполненным поясом, пустой пояс, разные артефакты двух игроков, именные/гибридные артефакты и распределение улучшений брони. Затем публиковать клиент вместе с серверным изменением.

Клиент проверен: pda_artifacts.test.js, pda_profile.test.js, character_portrait.test.js. Полный клиент в Chromium проверен при ширине 320/390/768: одинаковый размер восьми ячеек, сетка артефактов 3×2, частично заполненный и пустой пояс, 27 открытий/закрытий описаний, отсутствие ошибок JavaScript. Это автономные тестовые профили, не проверка реального чужого пояса на рабочем API.

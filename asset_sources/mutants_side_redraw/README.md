# Мутанты для боковой сцены боя

Пакет содержит **29 видов и покрывает все 57 записей** игрового каталога. Для мужского и женского варианта одного вида используется один PNG: различий внешности и дублирования файлов нет.

Все изображения заново нарисованы для противника справа: тело, голова и взгляд направлены влево, к персонажу игрока. Это новые ракурсы, а не зеркальное отражение прежних фронтальных картинок. Особенности известных мутантов сверялись с найденными изображениями серии S.T.A.L.K.E.R., преимущественно S.T.A.L.K.E.R. 2. Для авторских существ и отсутствующих в найденных материалах видов сохранён дизайн исходников `images/combat/mutants/`. Интернет-изображения использованы как референсы внешности, в игру включены новые рисунки.

Итоговые файлы находятся в `images/combat/mutants-side/<id>.png`. Рядом с этим документом для каждого вида сохранён JSON с источником, референсом, описанием генерации и результатом визуальной проверки. Восстановленные после прерывания работы изображения могут иметь `promptProvenance`: их описание явно отмечено как восстановленная спецификация, а не дословный первоначальный промпт. Абсолютные пути к рабочим файлам фиксируют происхождение; запуск игры от них не зависит.

PNG имеют настоящий канал RGBA. Перед подключением проверяются нулевой альфа-канал снаружи, отсутствие видимых пикселей на границе холста, размеры и нижняя граница силуэта. Порог видимости — альфа 16/255: возможный остаток 1/255 вне силуэта не считается его частью. Сами пиксели сборщик не меняет. Чистоту силуэта, направление взгляда, полноту лап, когтей и хвостов дополнительно проверяют визуально; числовая проверка альфа-канала не заменяет этот просмотр.

`images/combat/mutants-side/manifest.js` подключается раньше `side-scene.js` и задаёт `window.CombatMutantsSide`; тот же объект доступен через CommonJS для проверки. Манифест хранит путь, направление `left`, размеры, `groundY`, точки опоры `feet`, признак `floating` и при необходимости индивидуальную рамку `fit`. Координаты опоры берутся из метаданных; недостающие определяются по связным областям альфа-канала у нижней части тела.

Для наземных мутантов опорная линия боковой сцены — **y = 940** на холсте 1536 × 1024, совместно с персонажем и фоном. Тени следуют точкам лап. Полтергейст и огненный полтергейст сохраняют `floating: true`, парящее размещение и общую мягкую тень. Новые изображения уже смотрят влево и повторно не отражаются.

Версия пакета `mutants-side-20260925-v3` используется отдельно от версии персонажей: изменение версии манифеста обновляет адрес PNG и ключ сцены. Ошибка загрузки позволяет повторить запрос; для вида, указанного в новом манифесте, фронтальное изображение не подставляется вместо неудачно загруженного бокового.

В версии v3 сохранён точный одобренный PNG Стронглава без изменения пикселей: уникальный древний разумный родственник кровососа, задуманный ростом около трёх метров. Он стоит прямо и спокойно, с опущенными руками, массивными плечами и длинными мощными ногами. Кожа светлая альбиносная, глаза красные, многочисленные тонкие светлые щупальца образуют бороду с красными жалами; несколько укороченных щупалец имеют старые закрытые зажившие концы. Густые волосы головы и таза почти до колен переходят от седых корней к тёмно-болотным концам; заострённое ухо выступает из волос. На теле закрытые старые рубцы; кисти сохраняют локальные следы крови, человеческие стопы и когти ног чистые. Шипов, хитина и наружного позвоночного гребня нет. Видимая высота в сцене — 875 пикселей против 650 у кровососа, опорная линия y = 940. Одобрение автора, окончательные требования, референсы и точные промпты хранятся в `stronglav-approved-design.json`; `stronglav.json` содержит ссылку на этот источник, контрольную сумму сохранённого PNG и параметры размещения. Этот вариант заменяет промежуточный тёмный образ с четырьмя толстыми щупальцами.

Также в v3 увеличены Плоть и Чернобыльский пёс. Верх силуэта Плоти совмещён с уровнем груди персонажа: точка груди на исходнике первого костюма с пистолетом `(540, 450)` проецируется в y ≈ 433 на игровом холсте. При общей земле y = 940 видимая высота Плоти составляет около 507 пикселей. Чернобыльский пёс увеличен с 274 до 420 пикселей по высоте. Параметры других 26 видов сохранены; проверены отсутствие обрезания и пересечений с игроком.

Стронглав — уникальный мутант. По замыслу автора его нельзя использовать для обычных и случайных встреч. Для будущего отдельного задания предусмотрены появление отметки на карте, охота на него и уникальный артефакт в награду. Эта запись фиксирует требования: серверный запрет обычных встреч ещё не применён; само задание, его запуск, отметка и выдача артефакта здесь не реализованы.

Сборка и проверка перед публикацией из корня проекта:

```bash
python tools/build_side_mutants_manifest.py --complete
node tests/combat_mutants_side_scene.test.cjs
node tests/combat_mutants_scale.test.cjs
node tests/combat_mutant_ground.test.cjs
```

Сборщик создаёт манифест и `validation.json`, не изменяя изображения и индивидуальные JSON. Флаг `--complete` требует все 29 проверенных видов и соответствие всех 57 записей каталога. Без флага допускается промежуточный пакет; недостающие виды перечисляются в отчёте. Проверки сцены охватывают ориентацию, общий PNG для обоих полов, опорную линию и тени, отдельную версию кэша, повтор загрузки и сохранение прежнего рендерера.

# Проверенная графика боя

Подготовлены 26 пистолетов, 29 изображений монстров и ранее очищенные 288 слоёв рук. У всех передних слоёв настоящий альфа-канал. Белая и нарисованная шахматная подложки удалены; отдельно обработаны просветы внутри спусковых скоб и между конечностями. Светлая кожа, шерсть и блики на оружии сохранены. Позы и размеры исходных холстов не менялись.

В бою отображается только правая рука с оружием и рукавом выбранной брони. Левая рука остаётся в поиске артефактов. Проверены 2 496 сочетаний пистолета и брони: непрозрачное соединение запястья, отсутствие оружия слева. Рисунки монстров при выводе сохраняют исходные пропорции.

Кракозябра восстановлена из прежнего изображения «Кракозябра — серый мутант-падальщик», без перерисовки. Для Излома использован исправленный вариант ушей. Исходники изменяемых изображений сохранены в `originals`; JSON-манифесты содержат имена и идентификаторы источников. Отчёты содержат SHA-256 оригиналов и итоговых файлов.

## Превью

- `mutants-review-1.jpg` и `mutants-review-2.jpg`: все 29 монстров на светлой и тёмной подложке.
- `pistols-review-1.jpg` — `pistols-review-3.jpg`: все 26 пистолетов с правым рукавом.
- `combat-scenes-review.jpg`: 18 вариантов окружения для шести видов.

## Граница готовности

Полные комплекты «монстр + три окружения» собраны для кабана, плоти, изотопа, зомби, чернобыльского пса и шарнира. Окружения подобраны из сохранённых исходников по местности; соответствие старым `exec-*` именам не заявляется.

Следующим этапом всем оставшимся 23 видам назначены три варианта из проверенных окружений. Общие местности переиспользуются ссылками: дополнительных 69 копий файлов не требуется. Каталог содержит 29 полных комплектов. Актуальная проверка окружений и нападения описана в `../combat_environment_review/README.md`.

```bash
python tools/restore_combat_batch.py

```

Валидаторы проверяют декодирование, размеры, хеши, альфа-канал, ранее найденные остатки магенты, очищенные просветы и сохранность светлых деталей. Визуально просмотрены 29 монстров и 26 пистолетов на обеих подложках, увеличенные спусковые скобы и 18 собранных сцен. Тесты отрисовки используют `@napi-rs/canvas` из `CODEX_PRIMARY_RUNTIME_NODE_MODULES`.

# Исходники брони №16–96

Все 81 пары подготовлены и индивидуально проверены. Игровые файлы находятся в icons/ с номерами из ASSET_MANIFEST_16_96.json. Номера файлов в этой папке являются номерами КАТАЛОГА.

*_source.png — исходные результаты генерации; *_corrected.png — исправления иконок 40–43, которые заменяют соответствующий source. *_rgb_draft.png — ранние исходники №16. armor_char_N.png / armor_icon_N.png — полноразмерные прозрачные изображения. WebP — нормализованные игровые кандидаты. review_N.jpg — проверка каждой пары на светлом и тёмном фоне. visual_review.json фиксирует выполненный просмотр.

Для воспроизведения: export_keyed_armor.py сохраняет нативную прозрачность или удаляет цветную подложку; prepare_ratnik_16.py обрабатывает исходники №16. export_transparent_armor.py задаёт общий формат. install_reviewed_armor.py применяет словари клиента через аудит.

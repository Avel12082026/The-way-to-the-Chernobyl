# Окружение и ответные удары мутантов

Все 29 видов имеют по три окружения. Для оставшихся 23 видов назначены существующие проверенные местности: деревни, леса, промзоны и подземный тоннель. Общие фоны переиспользуются ссылками из `images/combat/environments.json`; это 87 сочетаний, а не 87 разных изображений. Самки используют изображения и окружения соответствующего вида.

Все 87 сочетаний отрисованы и просмотрены на максимальном выпаде. Размеры существ настроены по типу: двуногие, четвероногие, крупные и парящие. Пропорции сохраняются, силуэты остаются в кадре. Листы `environments-1.jpg` — `environments-6.jpg` содержат результаты проверки.

Исправления боя:

- Выстрел предшествует ответному выпаду; побег, аптечка, ожидание и расходник вызывают ответную анимацию, если сервер вернул ход врага.
- Промах врага также сопровождается выпадом. При подтверждённой победе погибший мутант не атакует.
- Повторное нажатие и использование другого расходника во время ожидающего боевого запроса не отправляют второй ход.
- Ответ от старого боя не меняет нового противника. Сетевая ошибка возвращает доступ к действию.
- Анимация прекращается при уходе со сцены, скрытии приложения и настройке уменьшения движения. Поздняя загрузка изображений не открывает закрытый бой.

Проверки:

```bash
node tools/build_combat_catalog.cjs
node tests/combat_environments_review.cjs
node tests/combat_animation.test.cjs
node tests/combat_turns.test.cjs
node tests/combat_assets.test.cjs
node tests/combat_scene_exclusion.test.cjs
python tools/validate_combat_transparency.py
python tools/validate_restored_combat.py
```

Тесты ходов используют моделируемые ответы сервера. Реальные серверные расчёты урона, выдача наград и поведение Telegram WebView требуют проверки в игре под аккаунтом игрока. Клиент продолжает использовать серверные значения и не вычисляет урон самостоятельно.

# Примерка оружия — 2026-09-23

Созданы 116 фиксированных слоёв оружия: 26 пистолетов/револьверов и 90 моделей под тяжёлую стойку. Каталог взят из игры, административное оружие 85 исключено. Не генерировать готовые слои заново.

192 исходных персонажа = 96 костюмов × 2 стойки. Просмотрщик соединяет каждый костюм со всеми 116 моделями: 11136 выбираемых сочетаний, не 11136 отдельно проверенных рисунков. Пистолеты только к вытянутым рукам, остальное к тяжёлой стойке. Без вспышек, направление вправо, прозрачный фон. Исходная броня, маски, капюшоны, перчатки сохранены.

weapons/ — исходные извлечённые PNG. fitting/weapons/ — очищенные фиксированные PNG, ID99 отражён вправо. fitting/characters/ — исходные персонажи. fitting/hands/ — передний слой кистей из этих же персонажей. placements.json — приблизительные якоря. web/ — облегчённая WEBP-примерка. SIDE-COMBAT-PREVIEW.html — автономный просмотрщик со всеми слоями, выбором костюма, оружия, увеличением хвата и экспортом прозрачного PNG. WEBP-примерка сжатая; PNG-исходники отдельно.

СТАТУС: создана полная модульная ПРИМЕРКА. В игру не подключена. Не считать все сочетания визуально одобренными. Проверены отдельные слои и выборочные сборки; есть недочёты хвата. У коротких тяжёлых моделей (4,8,9,43,62,73) вторая кисть может оказаться дальше цевья. У некоторых костюмов опорная кисть ниже оружия. Точное положение указательного пальца и рукоятки требует проверки каждой пары. Не скрывать эти ограничения.

Далее: просмотреть примерку, исправлять якоря и маски конкретных пар без повторной генерации оружия/брони; компактным моделям может понадобиться другая опора второй руки. Сохранять поправки в weapon-fit-adjustments.json из просмотрщика. Затем подключать согласованную модульную сборку в игру. Фоны встречи — отдельный этап.

Ранее сохранённый полный набор персонажей: SIDE-COMBAT-96-ARMORS-192-PNG.zip (libfile_e618ce352d348191a6b6aae73fc1cafa). Текущий архив продолжения SIDE-COMBAT-WEAPONS-CHECKPOINT.zip содержит все 116 исходных моделей, исходные карточки, настройки, программы, этот журнал. SIDE-COMBAT-FITTING-PNG.zip содержит готовые слои для сборки и PNG-просмотрщик.

Каждый следующий чат: сначала прочитать этот журнал, продолжать с сохранённых файлов; обновить запись о сделанном и конкретном остатке, сохранить её вместе с результатом для следующего чата. Не объявлять созданное подключённым или опубликованным в игре.

## Подгонка опорной кисти
Добавлен поворот фиксированного слоя вокруг основной кисти. Включён только для проверенных крупных примеров: оружие11 с бронёй7,8,10. На этих примерах устранён зазор по высоте между передней кистью и оружием. Размер и рисунок оружия сохранены. Это не означает готовности указательного пальца и всего хвата. Универсальный автоповорот намеренно НЕ включён: остальные пары требуют отдельной проверки. refine_support.py — эксперимент, не запускать автоматически: он создаёт непроверенные поправки всех тяжёлых пар. Авторитетны текущие placements.json и data.js. Следующее: подгонка коротких моделей и пальца на спуске; не переделывать уже готовые исходные изображения.

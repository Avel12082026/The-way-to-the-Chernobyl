# Уточнение приклада и перекрытия
Правило пользователя: приклад упирается в плечо; он не должен лежать поверх предплечья. Скрытая рукой часть должна перекрываться рукой, а не удаляться из исходника оружия. Проверять у каждого оружия с прикладом.

Разработан пробный слой перекрытия для броня7 / оружие11. Маска использует область ближней руки и альфа-канал исходного персонажа. Оружие не перерисовано. Начальный опыт скрытия за всем телом отклонён: скрывал слишком много приклада. Текущий опыт скрывает только за областью руки. Показан на compare-7.jpg, прозрачный вариант armor-7-weapon-11.png.

Это проба механизма перекрытия, НЕ утверждённая посадка в плечо: упор приклада и хват ещё надо довести. Маска ручная, только для брони7; граница приклада только для оружия11. Не распространять автоматически на другие костюмы/оружие. Старые пробные варианты 1/8/10 из локальной папки были опытом скрытия за всем телом — не применять.

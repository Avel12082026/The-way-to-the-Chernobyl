# Очистка графики перед обновлением

Это отчёт о первом этапе очистки. Актуальные результаты восстановления всех пистолетов и монстров приведены в `../combat_restoration/README.md`. Числа в разделе ниже относятся к первому этапу.

Исправлены исходные игровые слои без изменения позы, размеров холста и расположения силуэтов:

- 15 правых рук: удалены остатки магентовой подложки между деталями рукавов.
- 75 левых рук для поиска артефактов: очищены просветы между пальцами и снаряжением. В боевую сцену они не добавлены.
- Зомби и чернобыльский пёс: нарисованная шахматка заменена настоящим альфа-каналом; обработаны края силуэтов и шерсти.
- У Walther PPK сохранён проверенный прозрачный исходник. В отрисовке рукав накладывается поверх запястья с небольшим перекрытием, чтобы не было щели от двух совпадающих масок. Общая чёрная манжета не добавлялась.
- Обновлены версии URL изображений и скриптов, чтобы клиент не использовал старые изображения из кэша.

`transparency_report.json` содержит исходные и итоговые SHA-256, количество изменённых пикселей, размеры и проверку RGBA без потерь. Исходные руки восстанавливаются из коммита `f207bb0`; RGB-оригиналы двух монстров находятся рядом с этим файлом. Новые неудачные перерисовки ImageGen не устанавливались.

Проверка: декодирование всех 288 файлов рук, наличие альфа-канала, отсутствие обнаруживаемой магентовой подложки, проверка хешей 92 обработанных файлов. Отрисованы и просмотрены все 96 сочетаний Walther PPK с рукавами на светлой и тёмной подложке. Проверены увеличенные участки очистки, два монстра на обеих подложках. Тест проверяет отсутствие руки в левой половине боевого кадра, перекрытие запястья и различие всех 96 рукавов.

Воспроизведение:

```bash
python tools/clean_combat_transparency.py
python tools/validate_combat_transparency.py
node tests/combat_foreground.test.cjs
node tests/combat_scene_exclusion.test.cjs
node tests/combat_assets.test.cjs
node tests/combat_fitting_review.cjs
```

Для отрисовки используется установленный `@napi-rs/canvas` из `CODEX_PRIMARY_RUNTIME_NODE_MODULES`.

## Граница готовности

Это исправление имеющихся изображений, а не весь обещанный набор боевых сцен. В каталоге сейчас физически есть 1 из 26 пистолетов и 3 из 29 монстров. Полного набора «монстр + его три фона» нет ни для одного вида. Отсутствующие изображения не заменялись дублями и не отмечались готовыми. Полное обновление до их подготовки не готово. Проверка внутри Telegram не проводилась. Изменения пока не загружены на GitHub и не опубликованы в игре.

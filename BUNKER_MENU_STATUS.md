# Интерактивное главное меню Telegram — 17.09.2026

## Изменения

Главный экран использует утверждённое изображение `file_000000002bb08210800056ebfb1dce1f.png` из корня репозитория. Старые логотип, карточка персонажа и сетка кнопок главного меню заменены иллюстрацией с прозрачными областями нажатия.

- Леонов → `openScreen('scientists')`: существующая торговля и селекция артефактов.
- Жучара → `openScreen('shop')`.
- Дизель → `openScreen('technician')`: существующие торговля и улучшение.
- Дверь «Арена» → `openScreen('arena')`.
- Дверь «Склад» → `openScreen('warehouse')`.
- Открытая дверь «В рейд» → оригинальный `startRaid()` с блокировкой повторного запроса во время ожидания.
- Рюкзак → `openScreen('inventory')`.
- КПК → `openScreen('kpk')`.

Здоровье, сытость, жажда, Сталбайты, Сталкоины и Опыт+ отображают состояние `player`, обновляемое исходным `updateUI()`. Нарисованные образцы значений перекрыты непрозрачными внутренними областями интерфейса: при нуле не остаются старые цифры или цветное заполнение. Полоска здоровья учитывает `maxHealth`, еды/воды — `maxHunger`/`maxThirst`.

Опыт слева и радиация справа расположены в одной горизонтальной строке непосредственно над нижней панелью. Кнопка «Использовать» находится на месте нарисованной кнопки. Используется исходный серверный `/api/items/use-knowledge-book`; повторные нажатия блокируются до ответа. Ошибка соединения не списывает книгу локально.

Изображение и области нажатия масштабируются совместно. В портретной ориентации меню заполняет экран без обрезания дверей и нижней панели; в альбомной ориентации сохраняется вертикальная компоновка по центру. Музыка не отключается; отдельный значок её настроек скрыт только на главном экране, чтобы не перекрывать рисунок.

## Проверка

Контрольный GitHub Actions: run `35233307523`, workflow `Validate Telegram bunker menu`.

Проверен полный клиент с подменёнными ответами API, без операций над живыми профилями: 8 переходов; КПК → Телеграммка → Назад; отказ сервера при входе в рейд; защита от двойного входа; чтение книги, нулевой запас, ошибка соединения, повторные нажатия; нулевые/полные полоски; здоровье 89/150; большие суммы; одинаковая высота строк опыта/радиации; отсутствие пересекающихся кнопок и горизонтального переполнения. Размеры: 320×568, 360×800, 390×844, 412×915, 768×1024, 915×412. Ошибок JavaScript в проверке нет.

Скриншоты и JSON-отчёт сохранены в артефакте `bunker-menu-validation` этой проверки. Дополнительно пройдены проверка синтаксиса и `tests/chat_pda_structure.cjs`.

## Границы изменения

Только Telegram-клиент в `main`: `index.html`, `ui/bunker-menu.*`, установщик и тест. Android-ветки, APK, серверный код и данные игроков не изменялись. Проверка на физическом телефоне внутри Telegram остаётся за владельцем игры.

Точки поддержки: `ui/bunker-menu.html` — расположение областей; `ui/bunker-menu.css` — оформление; `ui/bunker-menu.js` — привязка к состоянию; `tools/install_bunker_menu.py` — одноразовое встраивание без переписывания остального клиента.

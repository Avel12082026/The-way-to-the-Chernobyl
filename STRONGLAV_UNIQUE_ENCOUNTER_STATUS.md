# Уникальный Стронглав: состояние серверной правки

В `tools/install_zone_map_routing_server.py` подготовлено исключение **Стронглава** и **Самки стронглава** из обычного случайного выбора на карте. Фильтр применяется после определения тира: остальные виды сохраняют свои локации, параметры и порядок. Если в выбранном тире остаётся только уникальный мутант, обычная встреча не создаётся.

Полный каталог, изображения и прямой доступ к определениям мутантов сохранены. Квест, маркер карты, уникальный артефакт и правила награды **не реализованы**: это отдельная будущая работа.

**На действующем сервере правка не применена.** `server.js` отсутствует в репозитории; доступ к актуальному серверному файлу и его запуску в этой сессии не подтверждён. Публикация клиентских PNG/HTML не меняет серверный выбор встреч. Старый генератор `raidCreateMutantPayload` известен лишь по упоминаниям в установщиках; его реальный код нужно прочитать и отдельно проверить до заявления, что уникальный мутант исключён из всех путей обычного появления. Подставлять выдуманную реализацию этого генератора нельзя.

Проверка подготовленного пути:

```bash
python tests/unique_stronglav_map_spawns.test.py
python tests/zone_map_server_patch.test.py
```

При наличии авторизованного доступа на сервер и загруженного обновлённого установщика сначала проверить совместимость:

```bash
python3 tools/install_zone_map_routing_server.py /var/www/pocketzone/server.js --check
```

Затем этот же установщик без `--check` создаёт резервную копию, обновляет поддерживаемый серверный код и перезапускает `pocketzone.service` с откатом при ошибке. Нужно запускать внутри серверного окружения с существующими файлами локаций и соответствующими правами; эта команда в текущей сессии не выполнялась.

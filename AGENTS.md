# Продолжение работ над игрой

Перед работой с руками и оружием прочитать HAND_PROGRESS.md, asset_sources/prepared_hand_pack/inventory.json и asset_sources/combat_hand_repair/review-log.json.

Прямая инструкция пользователя от 2026-09-15:
- Не начинать заново уже созданные рукава, перчатки, пистолеты и их посадку. Сначала найти существующий вариант и его запись.
- После каждого готового варианта сохранить файлы на GitHub отдельным коммитом в feature/android-local-assets и обновить HAND_PROGRESS.md: номер, что сделано, проверки, конкретный остаток.
- Подтвердить удалённый commit SHA. Локальный коммит не считать публикацией. При недоступности GitHub сохранить очередь и сообщить, а не повторять генерацию.
- Различать: создано, подключено, визуально проверено, опубликовано. Не объявлять весь набор готовым по проверке нескольких примеров.
- Проверять пальцы и хват каждого пистолета и детектора, прозрачность, текстуры, вспышку каждого пистолета после изменения.

- Каждый следующий чат обязан обновлять эту же памятку для следующего чата и сохранять это правило. Каждую выполненную задачу, даже малую, сразу записывать в памятку и публиковать на GitHub.

# Графика брони: текущее состояние

## Подключение

Клиент работает через GitHub Pages. Исправленные иконки №1–5 (`icons/armor_icon_1.webp` — `icons/armor_icon_5.webp`) и прозрачные персонажи №1–5 (`icons/armor_char_1.webp` — `icons/armor_char_5.webp`) загружаются через `getIconUrl()`. Для каждого файла в `CLIENT_ICON_VERSIONS` указан хеш содержимого: при замене изображения этот хеш нужно обновлять, чтобы кеш не показывал прежнюю картинку.

Другие изображения пока загружаются с Aeza, как раньше. Функция применяется во всех общих местах показа предметов и в портрете персонажа. Подготовленный новый файл следует добавлять в таблицу только вместе с самим файлом. Сервер, API и база игроков для этого не меняются.

## Правила новой серии

- Иконки показывают только пустую броню, одежду и прикреплённое снаряжение, без персонажа, головы, кожи, рук или манекена. Это уточнение пользователя заменяет прежнее требование о голове и плечах в PROJECT_HANDOFF.md.
- На иконках нет номера, названия, букв или текстовой плашки. Предмет целиком помещается внутри металлической рамки.
- Иконки №1–5 подготовлены из исправленных оригиналов в WebP, 384 × 384, качество 90; композиция сохранена.
- Каталожные названия, идентификаторы, параметры брони, улучшения +N и невидимые суффиксы экземпляров не меняются.

## Персонажи

Первые пять одобренных персонажей подготовлены с настоящим альфа-каналом. Игровые файлы — WebP RGBA 512 × 768; прозрачность сохранена без потерь, цвет сжат с качеством 90. Высота силуэта — 676 пикселей, верхняя и нижняя границы — 46 и 722, персонаж целиком помещается в кадре. Общий размер пяти файлов — 311 352 байта.

После трёх неудачных попыток генерации прозрачности пользователь предложил другой способ. Использована локальная маска фона готовых эскизов. Удаляется похожий на фон цвет, связанный с краями холста; непрозрачные внутренние пиксели персонажа сохранены побитово. Сглаживание и устранение примеси серого выполняются только в узкой полосе края. Картинки не перерисованы и не вырезаны из старых коллажей.

Обработка воспроизводится скриптом `tools/prepare_armor_sprites.py`. Проверенная среда: Pillow 12.3.0, NumPy 2.3.5, SciPy 1.17.0. Запуск из корня репозитория:

```bash
python3 tools/prepare_armor_sprites.py --source-dir /path/to/characters_preview --output-dir /path/to/alpha-output --game-icons-dir icons
```

Скрипт предназначен только для проверенных исходников 1024 × 1536 с почти однотонным фоном и этой позой. Он останавливается при неоднородном фоне или неожиданном контуре. Для следующих комплектов маску необходимо проверить отдельно; такой метод нельзя автоматически применять к произвольным изображениям. Исходные эскизы, прозрачные PNG, маски и фотографии проверки на двух подложках сохранены в пакете серии.

Все пять игровых изображений просмотрены на светлом и тёмном фоне. Проверены цельность макушки, рук, обеих подошв, сохранение тёмных ремней и обуви, прозрачность промежутков между руками и корпусом и между ногами.

## Проверка публикации

Проверить соответствие иконок и портретов всем пяти названиям, улучшенным и уникальным экземплярам, сохранение серверных URL для остальной графики и доступность файлов GitHub Pages. Визуальная проверка изображений и проверка файлов отдельно не заменяют проверку интерфейса в Telegram.

Следующая работа с графикой: комплекты №6–96 с индивидуальной проверкой исходников, масок и иконок. Нарисованная клетка не считается прозрачностью. Иконки остаются предметами без персонажа.

# Графика брони: текущее состояние

## Первая пятёрка

Подключён проверенный набор из CHERNOBYL_TRANSPARENT_ASSETS_CURRENT.zip: пять персонажей и пять иконок с настоящим альфа-каналом. Иконки изображают только пустую одежду, броню и прикреплённое снаряжение, без человека, манекена, текста и нарисованной рамки.

| № | Броня | Персонаж | Иконка |
|---|---|---|---|
| 1 | Комбинезон Юность | Новый прозрачный вариант | Прозрачная одежда без рамки |
| 2 | Куртка кожаная армейская | Новая исправленная версия с чистыми просветами у рук | Соответствующая куртка с нагрудными карманами |
| 3 | Ватник утеплённый | Новый прозрачный вариант | Завершённая прозрачная иконка |
| 4 | Плащ-палатка ОЗК | Ранее подготовленный прозрачный вариант | Прозрачный пустой плащ без рамки |
| 5 | Комбинезон Комбат | Новый прозрачный вариант | Завершённая прозрачная иконка |

Требование о пустой броне и прозрачном фоне заменяет прежние требования о голове и плечах и о металлической рамке. Не возвращать старые портретные или непрозрачные иконки. Персонаж №4 взят из ранее подготовленной версии: этот набор не означает новую перерисовку всех пяти персонажей.

## Игровой формат и подготовка

Персонажи: WebP RGBA 512 × 768, область размещения силуэта высотой 676 px, по центру, с верхним отступом 46 px. Иконки: WebP RGBA 384 × 384, предмет помещён в область 352 × 352 по центру. Качество цвета WebP — 90; альфа-канал при сохранении проверен побитово. Размер всех десяти файлов — 566 702 байта.

Экспорт из готовых PNG воспроизводится отдельно от удаления фона:

```bash
python3 tools/export_transparent_armor.py --collection /path/to/chernobyl-transparent-assets-current --icons-dir icons --report ASSET_MANIFEST_01_05.json
```

Скрипт сверяет исходные PNG с хешами в манифесте набора, проверяет RGBA, приводит масштаб и отступы к игровому формату и сохраняет WebP. Для расчёта границ он игнорирует одиночный шум с альфа 1–8 далеко от силуэта и оставляет три пикселя запаса по краю. Сам альфа-канал внутри выбранного кадра не заменяется новой маской. Отсечение заметных частей изображения останавливает экспорт. ASSET_MANIFEST_01_05.json содержит хеши исходников и игровых файлов, размеры и параметры размещения.

Прозрачность пары №2 и иконок №3/№5 подготовлена обработкой новых рисунков; не следует называть её нативным результатом генерации. Исходники и способы обработки сохранены в пакетах для просмотра. Нарисованная клетка не считается прозрачностью.

Старый tools/prepare_armor_sprites.py относится только к прежним эскизам с однотонным фоном. Для нового набора его не применять: поиск только связанного с краем фона может пропустить замкнутые просветы между руками и телом. Проверять нужно сам рисунок на светлой и тёмной подложке, а не только наличие альфа-канала.

## Подключение и проверка публикации

Клиент GitHub Pages загружает icons/armor_icon_1.webp — icons/armor_icon_5.webp и icons/armor_char_1.webp — icons/armor_char_5.webp через getIconUrl(). Для каждого файла в CLIENT_ICON_VERSIONS записаны первые 12 символов SHA-256. При замене изображения обновлять его версию вместе с самим файлом, чтобы кеш не показывал старую картинку.

Остальная графика остаётся на Aeza. Каталожные названия, идентификаторы, характеристики, улучшения +N, невидимые суффиксы экземпляров, сервер, API и база игроков не меняются.

Перед публикацией проверять соответствие пяти названий иконкам и персонажам, варианты с улучшениями и уникальными суффиксами, серверные адреса для остальных предметов. После публикации проверять GitHub Pages и хеши всех десяти скачанных WebP. Проверка файлов и изображений отдельно не заменяет визуальную проверку интерфейса внутри Telegram.

# Графика брони: текущее состояние

## Подключение

Клиент работает через GitHub Pages. Исправленные иконки №1–5 находятся в `icons/armor_icon_1.webp` — `icons/armor_icon_5.webp` и загружаются через `getIconUrl()`. Для каждого файла в `CLIENT_ICON_VERSIONS` указан хеш содержимого: при замене изображения этот хеш нужно обновлять, чтобы кеш не показывал прежнюю картинку.

Другие изображения пока загружаются с Aeza, как раньше. Функция применяется во всех общих местах показа предметов и в портрете персонажа. Подготовленный новый файл следует добавлять в таблицу только вместе с самим файлом. Сервер, API и база игроков для этого не меняются.

## Правила новой серии

- Иконки показывают только пустую броню, одежду и прикреплённое снаряжение, без персонажа, головы, кожи, рук или манекена. Это уточнение пользователя заменяет прежнее требование о голове и плечах в PROJECT_HANDOFF.md.
- На иконках нет номера, названия, букв или текстовой плашки. Предмет целиком помещается внутри металлической рамки.
- Иконки №1–5 подготовлены из исправленных оригиналов в WebP, 384 × 384, качество 90; композиция сохранена.
- Каталожные названия, идентификаторы, параметры брони, улучшения +N и невидимые суффиксы экземпляров не меняются.

## Персонажи

Пять одобренных эскизов персонажей в полный рост пока имеют серый фон и не заменяют игровые `armor_char_*.webp`. Они сохранены в пакете CHERNOBYL_ARMOR_01-05_DESIGN_PREVIEW.zip.

Следующий этап: получить настоящий альфа-канал, сохранив тёмную одежду и обувь; проверить края на светлом и тёмном фоне; выровнять позу, масштаб и поля; затем подключить новые файлы через ту же таблицу. Нарисованная клетка не считается прозрачностью. Старые дефектные вырезки не считаются финальной графикой.

## Проверка публикации

Проверить соответствие иконок всем пяти названиям, улучшенным и уникальным экземплярам, сохранение серверных URL для остальной графики и доступность файлов GitHub Pages. Визуальная проверка изображений и проверка файлов отдельно не заменяют проверку интерфейса в Telegram.

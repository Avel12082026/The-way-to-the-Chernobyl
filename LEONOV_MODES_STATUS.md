# Леонов: раздельные селекция и торговля

Обновление Telegram/web-клиента, BunkerMenu 1.2.0.

Рабочий код опубликован в `main` коммитом `c45a0c23b31d4a9de9c2211111c2765423485a42`.
Файл: `ui/bunker-menu.js`; проверенный Git blob: `b05cedfbc3e0103ab642e936f35a2de60c77da1d`.

## Поведение

- «Селекция» открывает только селекцию: исходные слоты 1 и 2, результат, одна кнопка «Селекционировать» на всю ширину. Ниже — сетка артефактов из рюкзака с перетаскиванием мышью и удержанием на сенсорном экране. Нажатие на заполненный слот освобождает его. Выбор в слот не списывает предмет.
- «Торговля» открывает отдельную панель с «Купить» и «Продать». Слоты и действие селекции в ней скрыты. Ассортимент, цены и серверные функции покупки/продажи не переписаны.
- Удалён поиск кнопки по тексту с автоматическим `.click()`: вход в меню больше не запускает селекцию.
- «Назад» из рабочего меню возвращает к изображению Леонова и его четырём действиям. Вход через склад тоже ведёт к этому меню.
- Двойное нажатие не отправляет второй запрос селекции, пока первый не завершён. Один экземпляр артефакта нельзя одновременно положить в оба слота.

Исходный HTML, серверная экономика и расчёт селекции не изменены. APK и Android-ресурсы не изменены.

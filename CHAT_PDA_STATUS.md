# Чат в КПК — Telegram-клиент

Правка от 17 сентября 2026 года. APK и серверные данные не изменяются.

## Изменения

- Встроенный чат и его контейнеры удалены из главного меню и рейда; убрана выделенная под чат строка сетки главного меню.
- В КПК добавлена кнопка «Телеграммка», открывающая отдельный экран существующего чата.
- Кнопка «Назад» возвращает из чата в КПК.
- Сохранены общий, фракционный и личный каналы, исходные API отправки, черновик при переходах и выбранный личный диалог.
- Отправка личного сообщения из профиля игрока теперь ведёт в новый экран, а не в главное меню.
- Индикатор новых личных сообщений также показывается на кнопке «Телеграммка».
- Возврат из рейдового рюкзака не переносит чат обратно в рейд. Изменение высоты чата больше не вмешивается в боевой интерфейс.
- Высота отдельного экрана чата учитывает visualViewport и экранную клавиатуру.

## Проверка

Проверенный index.html: SHA-256 `17306f97d562063d14c07a9f8abff52cc6d2e1f69b508eb66698471239227668`, Git blob `1f2140553572c1674bfc5acb6939c097e0bdee31`.

В Chromium проверены размеры 360×800, 412×915, 768×1024 и уменьшенная высота окна 360 пикселей: открытие из КПК, возврат, вкладки, отправка в три исходных API, отсутствие фракции, личные диалоги, сохранение черновика, переход из профиля, закрытие модальных окон, индикатор новых сообщений, вход/выход из рейда и возврат из рейдового рюкзака. Ошибок JavaScript в этих проверках нет.

Браузерные проверки выполнялись на реальном inline-клиенте с тестовым профилем и подменённым сетевым транспортом; реальные сообщения в чат не отправлялись. Внешние модули изображений, музыки и drag-and-drop в этом изолированном тесте не загружались. Проверка внутри Telegram на телефоне владельца остаётся отдельной пользовательской проверкой.

Структура, отсутствие старых контейнеров, маршруты кнопок и синтаксис inline-скриптов повторно проверяются командой `node tests/chat_pda_structure.cjs`.

Исходный клиент до правки: коммит `ddcd8dc253b3a1e50df37e0f784a80cfbb6ed5ea`. Вспомогательный workflow и скрипт применения остались только в рабочей ветке `work/chat-in-pda`; в main переносятся клиент, этот статус и структурный тест.
